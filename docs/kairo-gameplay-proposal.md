# 카이로소프트풍 게임성 제안서 (1~7단계 모두 승인·구현)

작성 2026-10-09. 이 문서는 **제안**이다. 기획자가 승인한 항목만 구현한다.
`docs/delivery-map-design.md`에서 확정된 것(노선 선택, 차량 지정, 차량 업그레이드, 명성으로 지역 해금, 기사 능력 기반 노선 이벤트)은 **바꾸지 않고 그 위에 얹는다**.

---

## 1. 지금 게임 루프와 문제점

### 지금 루프
손님 도착 → 접수 창구 → 포장대 → 선반 → 도크 → 대형 트럭 → 노선 지도 → 지역센터 → 배달 차량 → 수익·명성
→ 돈으로 건물·직원·차량·창고 확장, 명성으로 지역 해금.

### 재미가 얕은 이유
| # | 문제 | 지금 코드에서 보이는 모습 |
|---|---|---|
| 1 | **결정이 "더 사기"로 수렴** | 창구·포장대·선반을 늘리면 끝. 같은 구역 안이면 어디 놓든 효과가 거의 같다(동선 차이 정도). 공간이 모자랄 때도 고민할 게 "무엇을 뺄까"뿐 |
| 2 | **직원 성장이 한 줄** | 레벨 = 일한 시간(`xpNeed = 120×레벨`), Lv3에 특기가 자동으로 1개 붙고 끝. 직업·전직·스킬 선택이 없어 "키우는 맛"과 애착이 약함 |
| 3 | **발견할 것이 없음** | 숨은 조합·공식·도감이 없어 실험할 이유가 없고, 두 번째 플레이가 첫 번째와 같음 |
| 4 | **중기 목표가 약함** | 미션 17개가 순서대로 나오고 보상은 전부 돈. "다음 해금"이 기다려지지 않음 |
| 5 | **플레이어가 고르는 사건이 없음** | 노선 이벤트는 기사 능력으로 자동 판정(확정 사항이라 유지). 허브 안에는 선택형 사건이 없음 |
| 6 | **돈 쓸 곳이 적음** | 건물·직원·차량·확장뿐 → 중반 이후 돈이 남고 긴장이 사라짐(비용은 월급뿐) |
| 7 | **평가·의식(儀式)이 없음** | 하루 끝 월급 정산만 있음. 연말 시상식이나 등급 같은 "내가 잘했나"를 보여주는 순간이 없음 |

카이로소프트 게임(게임 발전 국 등)의 재미는 대략 이렇다: **① 키운 캐릭터에 대한 애착, ② 배치와 조합을 실험하다 발견하는 기쁨, ③ 짧은 주기의 평가와 긴 주기의 시상식, ④ 계속 열리는 새 장난감**. 아래 안은 이 네 가지를 택배 허브에 맞게 옮긴 것이다.

### A. 직원 직업 · 스킬 · 전직
지금 있는 능력치 5종(손속도·걸음·친절·체력·꼼꼼)은 그대로 두고, 그 위에 **직업**을 얹는다. 지금의 특기(접수 베테랑·포장 장인·쾌속 운반)는 직업으로 흡수한다.

| 기본 직업 | 맡는 일 | 직업 Lv별 스킬 (예) |
|---|---|---|
| 접수원 | 접수 창구 | Lv2 빠른 손(접수 −10%) · Lv4 미소 응대(손님 인내심 +15%) |
| 포장사 | 포장대 | Lv2 테이프 달인(포장 −10%) · Lv4 완충 마스터(파손 실수 −50%) |
| 운반원 | 운반 | Lv2 두 손 운반(2건 동시) · Lv4 지름길(걸음 +15%) |
| 분류사 *(신규)* | 선반·출고 | Lv2 색깔 분류(도크로 꺼내기 −20%) · Lv4 테트리스(선반 +5칸) |
| 상담원 *(신규)* | 창구 옆 상주 | Lv2 달래기 자동 · Lv4 VIP 전담(VIP 팁 2배) |

- 직업 경험치: 그 직업의 일을 할 때만 쌓인다. 필요량 Lv1→2: 100, →3: 250, →4: 500, →5: 900(게임 초).
- **전직(상위 직업)**: 직업 Lv5 + 관련 능력치 합 8 이상 + 비용
  - 접수원 → 창구 매니저(창구 2칸 동시 처리), 비용 8,000
  - 포장사 → 포장 장인(포장 −30%, 실수 0에 가까움), 8,000
  - 운반원 → 물류 달인(운반 3건), 8,000
  - 분류사 → 출고 반장(도크 싣기 ×1.5), 12,000
  - 상담원 → 고객만족 팀장(창구 3칸 범위 인내심 +25%), 12,000
- **숨은 직업 (발견 요소)**: 두 직업을 Lv5까지 키운 직원만 → 예) 접수원+포장사 = "원스톱 사원"(접수부터 포장까지 혼자), 운반원+분류사 = "자동화 설계사"(컨베이어 효율 +20%). 처음엔 직업 목록에 `???`로 보인다.
- 직업을 바꾸면 직업 레벨은 1부터 다시 시작한다. 예전 직업 레벨은 기록에 남는다(숨은 직업 조건용).

**[결정]** 누구를 어떤 직업으로 키울지 · 언제 바꿀지(일손 손실 vs 장기 이득) · 비용을 내고 전직할지
**[UI]** 직원 카드에 직업 아이콘과 직업 레벨 바 · 전직 화면(조건 체크리스트) · 스킬 목록 · 직업 도감
**[에셋]** 직업 아이콘 16px × 12종 · 직업별 겉모습(기존 걷기 시트 색 변형으로 처리, PixelLab 불필요) · 전직 반짝임 효과

### B. 시설 배치 인접 보너스 (세트)
같은 구역 안에서도 **어디에 무엇을 붙여 놓느냐**가 효율을 바꾸게 한다. 좁은 창고에서는 공간과 보너스 사이에서 고민이 생긴다.

| 세트 이름 | 조건 (맞닿게 배치) | 효과 |
|---|---|---|
| 포장 라인 | 포장대 2대 + 자재함 *(신규)* | 그 포장대들 속도 +15% |
| 대기 공간 | 접수 창구 + 대기 의자 *(신규)* 2개 | 그 창구 손님 인내심 +20% |
| 직원 카페 *(숨김)* | 휴게실 + 자판기 + 화분 *(신규)* | 휴게실 회복 ×1.3 |
| 물류 랙 | 선반 3개 일렬 | 각 선반 용량 +5 |
| 빠른 출고 *(숨김)* | 선반 + 컨베이어 *(신규)* + 도크 | 도크로 옮기는 시간 −30% |

- 판정: 건물 테두리가 한 칸이라도 맞닿으면 이웃으로 친다. 같은 세트는 겹쳐도 한 번만 적용.
- 반경형 소품: 화분은 반경 2칸 안 직원의 체력 소모 −5%(3개까지 겹침), 에어컨은 반경 3칸 −10%(여름 이벤트 때 ×2).
- 숨은 세트는 처음 발동할 때 "새 조합 발견!" 연출과 함께 도감에 등록 + 명성 +20.

**[결정]** 공간을 세트에 쓸지, 처리 시설을 하나 더 놓을지 · 확장 전 좁은 창고에서 배치 짜기
**[UI]** 설치할 때 미리보기(맞닿는 이웃을 초록 테두리로, 발동될 세트 이름 표시) · 세트 도감(숨김은 `???`)
**[에셋]** 새 소품 6~8종(자재함, 대기 의자, 화분, 컨베이어, 저울, 게시판, 에어컨) PixelLab 64 크기 1건씩(후보 16장) → **약 140~160회**

### C. 숨은 공식 · 조합 발견 (도감)
"해보니 되더라"를 모아 두는 곳. 도감은 세 권이다.
1. **세트 도감** (B): 공개 세트 5 + 숨김 세트 5
2. **직업 도감** (A): 기본 5 + 상위 5 + 숨은 직업 3
3. **손님 도감** *(신규)*: 특정 조건에서만 오는 손님
   - 단골 할머니: 대기 공간 세트 + 친절 4 이상 접수원 → 매주 김치 택배(급송) + 팁
   - 유튜버: 명성 300 이상 + 피버 중 → 다음 날 손님 +30%
   - 이삿짐 센터 사장: 대형 택배 누적 50건 → 대형 대량 주문 이벤트 시작

- 도감을 일정 수 이상 채우면 영구 보너스: 25% → 수익 +3%, 50% → 연구 속도 +10%, 100% → 전설 직원 후보 등장.

**[결정]** 조건을 추측하고 배치·직원 구성을 실험
**[UI]** 도감 화면(탭 3개, 실루엣 + 힌트 한 줄), 발견 팝업
**[에셋]** 특수 손님 3~5명: 기존 손님 시트처럼 PixelLab 캐릭터 + 걷기 → 손님 1명당 약 40~60회 → **약 150~250회** (줄이려면 기존 손님 색 변형으로 대체 가능)

### D. 연구 · 훈련
돈 쓸 곳을 늘리고 장기 목표를 만든다.
- **연구 포인트(RP)**: 택배 1건 배송 = 1 RP, 연구실 *(신규 시설, 3×3, 10,000)* 1개당 하루 +30 RP.
- **연구 트리 3갈래 × 5~6개** (RP + 돈 + 시간):
  - 작업: 바코드 접수(접수 −10%, 200RP) → 자동 테이프(포장 −15%, 500RP) → 포장 라인 2세대(세트 효과 ×1.5, 1,200RP)
  - 물류: 컨베이어 해금(400RP) → 분류 자동화(분류사 스킬 효과 ×1.5, 900RP) → 야간 출고(하루 끝에 남은 택배 자동 출고, 2,000RP)
  - 서비스: 번호표(인내심 +10%, 300RP) → 단골 카드(재방문 +, 700RP) → 프리미엄 배송(급송 보너스 ×2, 1,500RP)
- **직원 훈련** *(허브 직원용, 기사 훈련은 그대로 둠)*: 교육실 *(신규 시설)*에 보내면 하루 동안 일을 못 하고 능력치 하나 +1(최대 5). 비용 1,000 × 현재 능력치.

**[결정]** 어느 갈래부터 연구할지 · 바쁜 시기에 누구를 훈련 보낼지(일손 공백)
**[UI]** 연구 화면(트리, 진행 막대) · 교육실 배정 · 연구 완료 팝업
**[에셋]** 연구실·교육실 시설 2종(128 크기, 약 40회) · 연구 아이콘 16px 18개(코드로 그리거나 단순 도트)

### E. 랜덤 이벤트와 선택 (허브 안)
노선 이벤트(기사 능력 자동 판정)는 **그대로 두고**, 허브 안에만 **플레이어가 고르는** 사건을 넣는다. 하루 1~2번 팝업.

| 사건 | 선택지 A | 선택지 B |
|---|---|---|
| TV 취재 요청 | 받는다: 오늘 손님 ×1.5 + 대기 혼잡, 성공하면 명성 +50 | 거절: 변화 없음 |
| 명절 특수 | 특근: 3일간 택배 ×1.5, 월급 ×1.3 | 평소대로: 놓친 손님으로 명성 −10 |
| 직원 다툼 (A↔B) | 중재 비용 500: 둘 다 의욕 회복 | 놔둔다: 3일간 둘 다 능률 −15% |
| 대량 주문 제안 | 수락: 2시간(게임) 안에 급송 40건, 성공 +8,000 / 실패 명성 −30 | 거절 |
| 폭염 | 에어컨 임대 2,000: 체력 소모 정상 | 버틴다: 하루 동안 체력 소모 +30% |
| 신입 지원자 | 특별 채용(능력 높음, 월급 2배) | 다음 기회에 |

- 결과는 성공/실패 확률이 직원 능력·시설로 정해진다(예: TV 취재 성공 = 창구 수 × 0.15 + 상담원 Lv × 0.1).
- 같은 사건은 일주일에 한 번 이하.

**[결정]** 위험과 보상 사이 선택
**[UI]** 사건 팝업(그림 + 선택지 2개 + 예상 결과 힌트) · 진행 중인 사건 표시줄
**[에셋]** 사건 삽화 6~8장(64~128 오브젝트로 대체 가능, 약 120~160회) 또는 아이콘만(0회)

### F. 목표(마일스톤)와 보상
지금의 미션 17개를 **연차 목표 + 업적**으로 바꾼다. 보상을 돈만이 아니라 **해금**으로 준다.
- **연차 목표**: 1년(달력 단위는 결정 사항 D6)마다 목표 3개. 예) 1년차: 하루 처리 50건 / 만족도 B 이상 / 시내 지역 개설.
  - 3개 모두 달성: 다음 해 "새 장난감" 해금(새 시설·연구 갈래·직원 후보 등급↑ 중 하나) + 명성 +100
  - 일부 달성: 돈 보상만
- **업적(트로피) 30개 내외**: 누적 1만 건, 실수 0인 날 7일 연속, 숨은 세트 전부 발견 등. 업적마다 작은 영구 보너스(수익 +1% 등, 상한 있음).
- 기존 미션 보상 체계는 업적으로 흡수(세이브 이관).

**[결정]** 올해 목표에 맞춰 투자 방향 정하기
**[UI]** 목표 패널(연차 목표 3개 + 진행도) · 업적 목록 · 해금 연출
**[에셋]** 트로피·메달 아이콘 몇 개(PixelLab 32 크기 1건 = 후보 64장, 약 20회)

### G. 평가와 랭킹
짧은 주기 평가 + 긴 주기 시상식.
- **하루 정산 화면** (지금 월급 정산을 확장): 처리 건수, 평균 대기 시간, 실수율, 놓친 손님 → **S/A/B/C/D 등급**. 등급에 따라 명성 +30/+15/+5/0/−10.
- **만족도 별점**: 손님별 대기 시간·실수·VIP 처리로 1~5점 → 하루 평균이 등급과 명성에 반영.
- **연말 "택배 대상" 시상식**: 가상 경쟁사 5곳(이름·성장 곡선이 정해진 NPC 회사)과 연간 처리량·만족도·명성으로 순위. 1위: 트로피 + 명성 +300 + 특별 직원 후보. 3위 안: 명성 +100.
- 경쟁사는 해마다 커져서 늦게 성장하면 순위가 밀린다 → 긴장 유지.

**[결정]** 처리량(손님 많이) vs 품질(실수·대기 적게) 중 어디에 집중할지
**[UI]** 하루 정산 카드 · 연말 시상식 연출(순위 발표, 트로피) · 순위표
**[에셋]** 시상식 무대 배경 1장(코드로 그려도 됨), 경쟁사 로고 5개(작은 아이콘)

### H. 확장 단계 (회사 등급)
창고 확장 4단계(작은 창고~물류센터)와 별개로 **회사 등급**을 둔다. 등급이 오르면 기능이 열린다.

| 등급 | 조건 | 해금 |
|---|---|---|
| 동네 영업소 | 시작 | 기본 시설 |
| 지점 | 명성 100 + 하루 처리 40건 | 연구실, 대기 의자, 화분 |
| 거점 허브 | 명성 400 + 연말 3위 안 | 교육실, 컨베이어, 상위 직업 |
| 광역 물류센터 | 명성 1,200 + 직원 10명 | 숨은 손님, 자동 출고 연구 |
| 전국 네트워크 | 명성 2,500 + 택배 대상 1위 | 엔딩 + 무한 모드(경쟁사 강화) |

- 지역 해금(명성)은 확정 사항이라 그대로 둔다. 회사 등급은 지역 해금과 **같은 명성**을 쓰지만 추가 조건이 있어 따로 오른다.
- 선택 사항: 지역센터 레벨(노선 지도의 센터 건물이 커짐, 배달 차량 대기 칸 +1) — 노선·차량 규칙은 건드리지 않고 겉모습·보관량만.

**[결정]** 등급 조건을 맞추려 무엇을 먼저 키울지
**[UI]** 회사 등급 표시(상단 바) · 승급 연출 · 다음 등급 조건 카드
**[에셋]** 허브 외관 등급별 2~3종(128, 약 40~60회) — 노선 지도 허브 그림을 등급에 따라 교체
